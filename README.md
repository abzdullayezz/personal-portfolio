# Personal Portfolio — Vahid Abdullayev

Personal portfolio website of **Vahid Abdullayev**, a BSc Computer Science student at Transport and Telecommunication Institute (TSI), Riga, Latvia.

**Live site:** https://abzdullayezz.github.io/personal-portfolio/

## About

A single-page portfolio that presents my education, projects, activities and contact details. The content is written to be honest and specific: it states what I have actually built and what I am still learning.

## Features

- Responsive layout for desktop, tablet and mobile
- Light and dark theme (follows system preference, with a manual toggle)
- Smooth scroll navigation and scroll-reveal animations
- Contact form with client-side validation
- No frameworks or build step: plain HTML, CSS and JavaScript

## Tech stack

- HTML5
- CSS3 (custom properties, grid, flexbox)
- Vanilla JavaScript
- Fonts: IBM Plex Serif, IBM Plex Sans, IBM Plex Mono (Google Fonts)

## Project structure

```
personal-portfolio/
├── index.html    # the whole site (markup, styles, scripts)
├── README.md
└── .gitignore
```

## Run locally

No installation is needed. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Deployment

The site is deployed with GitHub Pages from the `main` branch, root folder.
