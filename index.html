Projects

What I've built

P-01 2026 In use
Guest Verification Panel
Latvia Azerbaijanis Association

The association needed a way to check guests at the door during events. I built a panel that scans QR codes and matches them against a registration list stored in an Excel file. If the code is valid, the guest's name and details appear on screen. It runs in a browser — no installation needed for the person at the door.

This is my first solo project from scratch. It is currently being used at association events.
